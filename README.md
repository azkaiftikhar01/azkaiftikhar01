### Selected projects

**[samey](https://github.com/azkaiftikhar01/samey)** · TypeScript, Node.js, Playwright · open source
A CLI that audits websites built with Claude Code, Cursor or Codex for what makes them look like every other one: stock gradients, the same card grid everywhere, template copy, dead links, mobile overflow. Every finding comes with evidence and a ready-to-paste fix prompt for your coding agent. Runs locally, with an SSRF-safe crawler and no API keys.

**[Leadboard](https://github.com/azkaiftikhar01/leadboard)** · Electron, React 19, Express, MongoDB
A voice-first cockpit for engineering team leads that lives in the macOS menu bar. Talk to it and it structures the captures into tasks. It runs the morning standup as a guided routine, and works out rework, delivery and deadline metrics from the work that's already happening.

**[Saveiour](https://github.com/azkaiftikhar01/saveiour-mobile)** · React Native, Expo, TypeScript, Reanimated
A savings-goal app for iOS and Android. It builds a weighted plan (payday rhythm, day of week, habit momentum) that always adds up to the target to the last paisa, and re-spreads it when you miss a day or save extra. Squads split group goals into exact shares and rank everyone on a leaderboard.

**[Phool For Your Fool](https://github.com/azkaiftikhar01/phoolforyourfool)** · Next.js, Prisma, PostgreSQL · [live](https://phoolforyourfool.vercel.app)
E-commerce for a florist: catalog, cart, JWT auth, checkout, gift cards, a custom bouquet builder, an admin dashboard and Cloudinary media.

**[Certified.io frontend automation](https://github.com/azkaiftikhar01/certifiedio-frontend-automation)** · Playwright, TypeScript, GitHub Actions
